# Privacy Policy for Opion

**Last updated: September 27, 2026**

Opion is designed with privacy-first principles. 

### Data Collection and Transmission
- **No Network Access:** Opion does not request or use internet permissions (`android.permission.INTERNET`).
- **No Data Collection:** Opion does not collect, record, or track any personal data, identifiers, or device information.
- **Zero Telemetry:** The application contains no analytics, telemetry services, crash-reporting SDKs, or third-party trackers.
- **Local Processing:** All actions (EXIF sanitization, link cleaning, clipboard clearing, and security diagnostics) are executed strictly on-device in volatile memory.

### Changes to This Policy
If any future update introduces changes, this document will be updated accordingly.

### Contact
If you have any questions regarding this policy, you can open an issue on this repository.
